# 短周期回看：下一版本设计清单

当前 V1 的回忆页只负责从作品和便签生成回忆卡。下一版应做短周期回看，例如七日回顾或月度创作回看；它借鉴年报的叙事和动效形式，但不等待一整年数据沉淀。

下一版本开始前，由产品方填写以下内容：

- 回看名称和开场文案。
- 展示周期：七日回顾或月度回看。
- 动画页面顺序：创作次数、数据时刻、最被喜欢的作品、便签片段、社区互动、结尾寄语。
- 每一页的标题、正文和数据描述口径。
- 是否允许用户保存为图片或视频。

开发入口：`src/App.tsx` 中的 `Memories` 组件。完成设计后，将它改为可点击卡片，并新增 `MemoryRecapPage` 作为全屏、逐页播放的页面。
