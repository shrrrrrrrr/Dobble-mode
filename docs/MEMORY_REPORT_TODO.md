# 短周期回看：V1.4 七日回看

V1.4 已将短周期回看实现为最近七天体验。它借鉴年报的逐页叙事形式，但只统计今天及之前 6 天的数据，不等待一整年数据沉淀。

## 当前实现

- 作品按 `publishedAt` 筛选最近七天。
- 反馈按 `createdAt` 筛选最近七天。
- 首页的近期作品、点赞和反馈统计只使用最近七天数据。
- 回忆页的回忆卡和 `WeeklyRecap` 全屏逐页页面只使用最近七天数据。
- 没有最近七天作品时显示空状态，并提供返回回忆页的入口。

## 当前未包含

- 月度或年度回看。
- 回看内容导出为图片或视频。
- 云端同步和真实多用户数据流。
- 自动生成文案或真实 AI 接入。

实现入口：`src/App.tsx` 中的 `Memories` 和 `WeeklyRecap` 组件，以及 `getRecentSevenDays`、`isInRecentSevenDays` 日期筛选函数。
