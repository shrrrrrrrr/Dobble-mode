# 短周期回看文案指南

## 当前已实现的模板

「回忆」页只统计今天及之前六天的数据，并以四页可重新播放的叙事展示：

1. 本周创作数量：`recent.length`
2. 本周最高喜欢作品：`favorite.title` 与 `favorite.likes`
3. 创作者当时留下的作品便签：`recent[0].note`
4. 珍藏反馈数量与第一条反馈：`recentFeedback.length`、`recentFeedback[0].content`

无作品时，会改为一页空状态。当前没有月报、年报、人格标签、平台画像、导出长图或视频，因此不能声称 QQ 或 B 站年报的多套模式已经完成。

## 手动改文案的位置

当前模板位于 `src/App.tsx` 的 `WeeklyRecap` 组件。请只修改 `slides` 数组中每页的固定中文句子，保留花括号中的数据变量，例如：

```tsx
<p>条作品被认真留了下来。</p>
<p>个喜欢，是这周最明亮的回应。</p>
```

不要改动 `recent`、`favorite`、`recentFeedback` 的计算逻辑，否则可能影响七天筛选和空状态判断。

## 后续模板扩展建议

新增短周期模板时，建议继续使用 7 天或 30 天为周期，并让每个模板由“数据事实 + 创作者自己的便签/反馈”组成。可优先增加：连续创作天数、最常发布的平台、最常记录的心情、某一条暖心评论的放大页。年度报告应等用户有足够历史数据后再做，且应由用户先确认叙事文案。
