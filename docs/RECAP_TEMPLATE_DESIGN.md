# 回忆模板设计与媒体采样（V3.8）

## 你应该编辑哪里

- **叙事文案：** `src/data/recapTemplates.ts`。这里是所有可由产品负责人自行改写的标题、眉标和说明文字。
- **页面顺序与数据口径：** `src/App.tsx` 的 `WeeklyRecap`。除非要改变“最近七天”“最受欢迎作品”“珍藏反馈”的规则，否则不要直接改这里。
- **媒体截图算法：** `src/utils/recapMedia.ts`。一般不需要改；改动会影响存储容量和截图质量。

## 当前回忆模板

1. 本周创作数量。
2. 最高喜欢的作品与点赞数据。
3. 可选的“留住画面”页：展示该作品上传媒体生成的 1–3 张画面。
4. 作品便签。
5. 珍藏反馈。

没有作品时使用单页空状态。该产品仍是七日短周期回看，不是年报。

## 媒体截图规则

在“记录一条作品”中，可上传最多 6 个图片或视频文件作为“回忆画面”。图片会压缩后直接进入回忆；视频不保存原文件，而是在浏览器本地从 **14%、28%、43%、58%、72%、86%** 的中段候选时间点采样。

每个候选帧都会检测亮度、对比度和颜色指纹：过暗/低信息画面会跳过，相近画面会去重，最后按时间顺序保留最多 3 张。它不会只取首帧或末帧。单个视频上限为 100 MB。

当前保存的是压缩截图，不是原视频。原视频上传、跨设备播放和长期媒体库需要后续接入 Supabase Storage 的私有上传与签名 URL，不能把大视频塞进浏览器或 JSONB 快照。
